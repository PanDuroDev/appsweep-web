A little about AppSweep

AppSweep is an experimental Windows app manager and deep uninstaller, built with Rust, egui, and a C++ helper. It brings installed software, available metadata, and related locations into a more informed workflow.

It is still earlier than beta. Detection may be incomplete, features can change, and a public build may not exist yet.
