A clearer view of what's installed.

AppSweep is an experimental Windows 10/11 app manager and deep uninstaller, built with Rust, egui, and a C++ helper. It aims to help you discover installed software, inspect available metadata, and review related paths. It is still in pre-alpha: expect unfinished features, bugs, and breaking changes.

BUILT AROUND CLARITY

Know what you're looking at.

The project is under active early development. Detection coverage and displayed metadata depend on the Windows environment and may be incomplete; features and behavior can change before beta.

01 / DISCOVER
apps

Find applications in more places

Designed to discover software through Windows uninstall records, Store app entries, and Start Menu shortcuts. Coverage is still evolving.

02 / INSPECT
manage_search

Understand the available details

Inspect available details such as publisher, version, install location, architecture, and uninstall data when present.

03 / REVIEW
folder_open

Check related paths

Review app-related locations and potential leftovers. Results are best-effort and may miss files or show paths that need manual verification.

A MORE INFORMED WORKFLOW

Look closer.
Then decide.

AppSweep is pre-alpha and should be treated as experimental software, not a dependable cleanup or security tool. Review every result carefully, back up important data, and never delete a path just because it appears related.
