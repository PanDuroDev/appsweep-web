GOOD TO KNOW

Questions,
answered.

Want the technical details? The repository is the source of truth for the latest project status.

Is AppSweep free and open source?

Yes. The source code is publicly available on GitHub. Review the repository for the current license and project status.

Which platform is it for?

AppSweep is a Windows desktop application. It uses Windows-specific app discovery and management capabilities, so it is not a macOS or Linux uninstaller.

Does this website uninstall apps?

No. This website is the project landing page. App discovery and management happen in the AppSweep desktop application on Windows.

Is there a download available now?

Check the GitHub Releases page for published builds. If no release is listed, a packaged download may not be available yet; the source code remains available in the repository.

Can leftover files always be safely deleted?

No. A file or registry entry can be shared or misidentified. Review what is detected and make sure you understand the consequences before removing anything.
