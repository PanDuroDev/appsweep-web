AppSweep is a Windows desktop application for discovering installed software, inspecting its available details, and reviewing related traces before taking action.

Download from GitHub ↗ View source

Downloads are provided through GitHub Releases when a release asset is published. If no downloadable file is listed, check the repository for the latest project status.

WHAT IT DOES

Focused tools, no fictional screenshots.

01

Find installed applications

Collects application entries from Windows registry uninstall records, Store apps, and Start Menu shortcuts.

02

Inspect available details

Shows available information such as publisher, version, install location, architecture, and uninstall information.

03

Review related paths

Helps inspect detected app-related locations and leftover traces. Results depend on the information available on the device.

04

Open-source Windows utility

The application is built with Rust and egui, with Windows-specific functionality. Read the source and report issues on GitHub.
