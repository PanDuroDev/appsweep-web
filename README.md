# AppSweep Web

The public landing page for [AppSweep](https://github.com/PanDuroDev/appsweep), an open-source Windows app manager and deep uninstaller.

## Stack

- Semantic HTML
- CSS with a Material Design 3-inspired dark color system and responsive layouts
- Vanilla JavaScript for lightweight navigation interactions
- GitHub Pages for hosting, deployed by GitHub Actions

No package manager, bundler, runtime, or API key is required.

## Local preview

Open `index.html` in a browser, or serve this directory with any static HTTP server.

## Deployment

The workflow in `.github/workflows/pages.yml` deploys the repository root to GitHub Pages whenever a commit is pushed to `main`, and can also be started manually from the Actions tab.

If GitHub Pages has not been enabled for this repository yet, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source. The intended live URL is:

https://pandurodev.github.io/appsweep-web/
