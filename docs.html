GET A BUILD

Download AppSweep

Open the GitHub Releases page and download a release asset if one is available. If no executable or archive is listed, there may not be a published build yet. Avoid unofficial download mirrors.

Check releases ↗
02

FROM SOURCE

Build on Windows

Install a current Rust toolchain and the Windows build prerequisites required by the project. Then run these commands in PowerShell or your terminal:

git clone https://github.com/PanDuroDev/appsweep.git
cd appsweep
cargo build --release

The release binary is normally placed under target\release\. If the build fails, check the error output and the repository's latest instructions for required native tools.

Review source repository ↗
03

BEFORE TAKING ACTION

Inspect, don't assume

Application metadata and detected paths may be incomplete or outdated. Verify the selected application, publisher, and purpose of any related location before uninstalling software or removing files. Deleting the wrong item can break applications or Windows components.

!

Important
Do not treat a detected path as proof that it is safe to delete. Back up important data and use Windows' normal uninstall process where appropriate.

04

QUESTIONS OR BUGS

Get help

Open a GitHub issue and include your Windows version, the AppSweep version or commit, clear reproduction steps, and relevant error logs. Remove personal information and sensitive paths before posting.
