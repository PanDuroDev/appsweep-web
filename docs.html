Getting started with AppSweep.

A short guide to finding a build, running AppSweep, and getting help. Details may change as the project evolves; the repository is the source of truth.

Open releases ↗Repository

01 / DOWNLOAD

Get a published build

Open the GitHub Releases page and download an asset if one is available. If no release file is published, use the repository to check the current build instructions. Do not download executables from unofficial mirrors.

02 / BUILD FROM SOURCE

Build on Windows

AppSweep is a Rust project. To build it from source, install the Rust toolchain and the required Windows C++ build tools, then run these commands from PowerShell or a terminal:

git clone https://github.com/PanDuroDev/appsweep.git
cd appsweep
cargo build --release

The release build is normally written under target\release\. Native build prerequisites may be required; see the repository and build errors for current requirements.

03 / USE

Inspect before removing

Use AppSweep to review the installed-app entries and the information available for each one. Detected paths and metadata can be incomplete. Carefully verify the selected app and any related paths before confirming an action; removing software or files can affect your system.

04 / HELP

Report a problem

For bugs, questions, or feature requests, open an issue on GitHub Issues. Include your Windows version, the AppSweep version or commit, steps to reproduce, and relevant logs. Do not post private information or sensitive system paths.
