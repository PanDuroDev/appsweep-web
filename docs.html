02

FROM SOURCE

Build on Windows

The project uses Rust, egui, and a C++ helper, so the required Windows native build tools may depend on the current source. Check the repository README and workflow instructions first. If the project prerequisites are installed, start with:

git clone https://github.com/PanDuroDev/appsweep.git
cd appsweep
cargo build --release

A successful Cargo build does not guarantee every native helper or runtime dependency is packaged correctly. Treat build instructions as subject to change while the project is pre-alpha; inspect the current repository for the latest requirements.

03

BEFORE TAKING ACTION

Inspect, don't assume

AppSweep is still earlier than beta. Discovery, metadata, uninstall behavior, and path detection may be incomplete, inaccurate, or change without notice. Verify the selected application, publisher, and purpose of every location. Deleting the wrong item can break applications or Windows components.

priority_high

Important
Do not treat a detected path as proof that it is safe to delete. Back up important data, test cautiously, and prefer Windows' normal uninstall process when appropriate.

04

QUESTIONS OR BUGS

Get help

Because this is pre-alpha, bug reports and clear reproduction steps are especially useful. Include your Windows version, the AppSweep version or commit, what you expected, what happened, and relevant error logs. Remove personal information and sensitive paths before posting.
