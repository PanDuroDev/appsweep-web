Before you begin

AppSweep is in pre-alpha, earlier than beta. Expect incomplete features, bugs, changing behavior, and potentially unavailable builds. It uses Rust, egui, and a C++ helper.

warning

Experimental software, not a stable release. Do not rely on it for critical system maintenance. Back up important data before testing.

Build on Windows

The required Windows native build tools may depend on the current source. Check the repository README and workflow instructions first. If the project prerequisites are installed, start with:

git clone https://github.com/PanDuroDev/appsweep.git
cd appsweep
cargo build --release

A successful Cargo build does not guarantee every native helper or runtime dependency is packaged correctly. Treat build instructions as subject to change while the project is pre-alpha; inspect the current repository for the latest requirements.

Inspect, don't assume

Discovery, metadata, uninstall behavior, and path detection may be incomplete, inaccurate, or change without notice. Verify the selected application, publisher, and purpose of every location. Deleting the wrong item can break applications or Windows components.

warning

A detected path is not proof that it is safe to delete. Back up important data, test cautiously, and prefer Windows' normal uninstall process when appropriate.
